HUONG DAN CAI DAT CLIENT SHOPBANHANG
====================================

API dang dung:
https://shopbanhang-api.onrender.com/api/

BUILD GOI CAI
-------------
1. Kiem tra file installer\remote-server.url co noi dung:
   https://shopbanhang-api.onrender.com/api/

2. Build bo cai:
   .\build-setup.ps1 -Force

3. Copy thu muc sau sang may can cai:
   dist\ShopBanHang-Installer

MAY CLIENT
----------
1. Chay setup.exe.
2. Setup se cai app va tao server.url tro ve Render API.
3. Dang nhap admin/quan ly de dong bo danh muc, san pham, nhan vien.
4. Tai khoan NV chi ban hang va dong bo hoa don/khach hang/ton kho; khong co quyen them sua san pham, chi nhanh, nhan vien.

NEU DOI API URL
---------------
- Sua file installer\remote-server.url.
- Chay lai .\build-setup.ps1 -Force.
- Cai lai setup.exe tren may client, hoac mo app -> Cau hinh server de doi URL.
